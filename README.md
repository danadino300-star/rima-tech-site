# Rima Tech — site officiel

Site vitrine pour la chaîne YouTube Rima Tech (@RimaTechDZ) et ses réseaux sociaux.

## Structure
```
rima-tech-site/
├── index.html      -> la page du site
├── assets/
│   └── logo.png     -> logo de la chaîne
└── README.md
```

## Héberger sur GitHub Pages
1. Crée un nouveau dépôt sur GitHub, par ex. `rima-tech-site`.
2. Ajoute tous les fichiers de ce dossier (`index.html` + dossier `assets/`) au dépôt (glisser-déposer sur github.com ou `git push`).
3. Dans le dépôt : **Settings** > **Pages**.
4. Sous "Build and deployment", choisis **Deploy from a branch**, branche `main`, dossier `/root`. Clique **Save**.
5. Attends 1-2 minutes : ton site sera en ligne sur `https://TON-PSEUDO.github.io/rima-tech-site/`.
